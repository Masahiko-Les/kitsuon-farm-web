# 吃音農場 サポート

吃音農場は、吃音のある人が苦労を「種」として蒔き、ほかの村人が優しい言葉の手紙で「水やり」をする、iPhoneアプリです。

## よくある質問

### 種はどうやって蒔くの？
農場の畑や草のマスに立ち、Aボタン（「蒔く」）を押します。20字以上、10行・300字まで書けます。1つのマスに蒔ける種は1つです。

### ほかの人の種はどこにあるの？
ふだんは見えません。2マス以内に近づくと光ります。光っている種の上に立ち、「水やり」を押すと読めます。

### 水やりの手紙は何通まで届くの？
1つの種に、5人まで水やりできます。1人1回です。

### 作物はいつ実るの？
種を蒔いた人が、届いた手紙に「ありがとう」を押すと実ります。作物は、蒔いた人と水やりした人の2人に届きます。

### いやな手紙が届いたら？
手紙の画面にある「この手紙を通報する」を押してください。通報した手紙は、すぐに郵便受けから消えます。「この人をブロックする」を押すと、その人からの手紙は届かなくなります。
