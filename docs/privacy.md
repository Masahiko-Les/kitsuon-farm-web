# プライバシーポリシー

吃音農場 運営（以下「運営」）は、iPhoneアプリ「吃音農場」（以下「このアプリ」）で扱う情報について、次のとおり定めます。

## 1. 集める情報

このアプリは、メールアドレスや電話番号での登録を必要としません。集めるのは、次の情報だけです。

| 情報 | 内容 |
| --- | --- |
| 匿名ID | はじめて起動したときに自動で作られる、ランダムな識別番号です。お名前や端末とは結びつきません。 |
| 村人名 | あなたが決めた、アプリの中での呼び名です。 |
| 種 | あなたが書いた文章と、蒔いたマスの場所です。 |
| 手紙 | あなたが書いた水やりの手紙と、送った相手です。 |
| 作物の記録 | 「ありがとう」で実った作物と、その種と手紙の文章です。 |
| 通報とブロック | あなたが通報した種や手紙、ブロックした相手です。 |
| 規約への同意 | 同意した日時と、利用規約の版です。 |

また、次の情報はサーバーに送らず、あなたの端末の中だけに保存します。

- 表示しないようにした種
- 読んだお礼のメッセージ

このアプリでは、次のものを**集めません**。

- 本名、住所、メールアドレス、電話番号
- 位置情報、連絡先、写真
- 広告のための識別子

広告は表示しません。アプリやウェブサイトをまたいで、あなたの行動を追うこと（トラッキング）もしません。

## 2. 使いみち

集めた情報は、次のことだけに使います。

- 種を蒔く、水やりの手紙を届ける、作物を実らせる、思い出帳を見せる、といったアプリの機能を提供するため
- 通報された書き込みを確認し、規約に反するものを削除するため
- 命に関わるようなつらい気持ちが書かれた種を、公開する前に確認するため

## 3. ほかの村人に見えるもの

- **村人名**：あなたの種を見つけた人と、手紙のやり取りをした相手に見えます。
- **種の場所**：種があることは、近くを通った人にわかります。
- **種の文章**：その種を見つけた人が読めます。
- **手紙**：送った相手だけが読めます。
- **作物の記録**：種を蒔いた人と水やりをした人の、2人だけが読めます。

## 4. 情報の保管と委託

情報は、Google LLC が提供する Firebase（Cloud Firestore と Firebase Authentication）に保存します。

- 保存先のサーバーは、日本の外（アメリカ合衆国など）にある場合があります。
- Google は、運営の委託を受けて情報を保管します。
- Google での情報の扱いについては、[Firebase のプライバシーとセキュリティ](https://firebase.google.com/support/privacy)をご覧ください。

運営は、法令にもとづく場合を除き、あなたの同意なく情報を第三者に提供しません。

## 5. 保存する期間と削除

情報は、あなたが削除するまで保存します。

アプリの「設定」→「すべてのデータを削除」から、いつでも次のものを削除できます。

- あなたの種
- あなたが送った手紙と、受け取った手紙
- あなたが関わった作物の記録
- 村人名などの登録情報と、匿名ID

ご注意いただきたいこと：

- 手紙と作物の記録は、やり取りをした相手の郵便受けと思い出帳からも消えます。
- 次のものは、安全のための記録として残ります。
  - あなたが送った通報の記録
  - ほかの人の種に残る「水やりをした人」の匿名ID（水やりの人数を数えるために使います）
- 運営は、規約に反する書き込みを、あなたの操作を待たずに削除することがあります。

## 6. お子さまの利用について

このアプリは、年齢によって使える機能を分けていません。未成年の方は、保護者の方と一緒にこのポリシーと利用規約を読んでから使ってください。

## 7. このポリシーの変更

内容を変えるときは、このページを更新し、大切な変更はアプリの中でもお知らせします。
